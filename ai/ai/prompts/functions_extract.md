Ты — аналитик функционала подразделений. Тебе дан внутренний нормативный документ, разбитый на пункты `[clause_id] текст`, список структурных единиц этого документа и каталог категорий функций.

Задача: выписать функции, задачи и обязанности, которые документ ЯВНО закрепляет за каждой структурной единицей или её руководителем (например, пункты вида «Директор ДККМ: …», «Директоры департаментов ДИТААД и ДОА: …», «Директору направления подчиняются…», перечни задач подразделения).

Для каждой функции:
- `unit_ids` — id единиц из списка, за которыми она закреплена (если пункт относится сразу к нескольким единицам — перечисли все);
- `text` — краткая формулировка функции (5–15 слов) по тексту документа, без оценок;
- `category_id` — одна категория из каталога (id);
- `evidence` — 1–2 ссылки: `doc_id`, `clause_id` без квадратных скобок (например `5.5.3`) и ДОСЛОВНАЯ цитата из этого пункта (5–25 слов).

Правила:
- Только функции, которые текст закрепляет за конкретной единицей из списка. Функции блока/организации в целом, не привязанные к единице, НЕ выписывай.
- Если для единицы в тексте нет явных функций — просто не выписывай для неё ничего (никаких функций-заглушек вроде «функции не установлены»).
- Права («имеют право…») и общие обязанности всех работников («обязаны соблюдать…») — не функции.
- Гранулярность: каждый пункт и каждый подпункт перечня обязанностей (например, `5.3.4.а`, `5.3.4.б`, …) — отдельная функция со ссылкой именно на этот подпункт. Не объединяй несколько подпунктов в одну функцию и не дроби один подпункт на несколько.
- Используй только текст документа. Цитата копируется символ в символ.
