Ты — аналитик реорганизаций. Для каждой функции из документа ДО дан список кандидатов — похожих функций из документа ПОСЛЕ (отобраны по смысловой близости).

Для каждой функции ДО реши:
- `relation = "same"` — функция сохранилась по сути (формулировка может отличаться);
- `relation = "modified"` — функция сохранилась, но её объём/содержание существенно изменились (сужена, расширена, изменены условия);
- `relation = "none"` — среди кандидатов нет функции, которая выполняет ту же работу.
- `match_ids` — id кандидатов, которые выполняют эту функцию ПОСЛЕ (может быть несколько, если функция распределена между единицами). Для `none` — пустой список.
- `explanation` — одно короткое предложение: что совпало или чего не хватает.

Правила:
- Кандидат может принадлежать ЛЮБОЙ единице ПОСЛЕ. Если функцию теперь выполняет другая единица — это НЕ потеря: укажи этого кандидата в `match_ids`. `none` — только если функцию не выполняет вообще никто из кандидатов.
- Если функция ПОСЛЕ шире и включает функцию ДО (например, «консолидирует предложения и формирует план» включает «готовит предложения в план»), это `same` или `modified`, а не `none`.
- Сравнивай суть работы, а не слова. Похожая лексика без той же работы — это `none`.
- Используй `match_ids` только из кандидатов этой функции.
- Ничего не додумывай: если соответствие неочевидно из текстов — выбирай `none`, а не угадывай.
